# Transformation Engine v4 — Monday Ready

Static Vercel package. Upload the loose files at the repo root; do not upload `dist`.

## v4 changes
- Cleaner home dashboard.
- Health metrics/recovery layer removed.
- Weekly report is range-based: current week to date, plan to date, full plan, or custom range.
- Expanded meal library is used more actively.
- Diet macros are generated from ingredient quantities rather than target labels.
- Two-portion batch labels for batchable meals.
- Home gym equipment option with dumbbell, bench, wall-band and loose-band substitutions.
- Optional hybrid lift behaviour is explicit.
- Structured Cardio/Swim retained as first-class planned session.
